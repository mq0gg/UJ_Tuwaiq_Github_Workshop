    // CHEAT SHEET

    الأوامر اللي بتحتاجها

    انسخ أي أمر بضغطة. الكلمات البرتقالية تكتب مكانها القيمة حقتك.

    bash — cheat-sheet

    # START

    $ git clone <url>

    تنزّل نسخة كاملة من الـRepository على جهازك

    $ git status

    وش وضع ملفاتك الحين؟

    $ git branch

    تعرض الـbranches وتوريك أنت على أي واحد

    $ git switch -c <branch-name>

    تسوي branch جديد وتنتقل له

    $ git switch <branch-name>

    تنتقل لـbranch موجود

    # SAVE & PUSH

    $ git add .

    تجهّز كل التعديلات للـcommit (Staging)

    $ git commit -m "message"

    تحفظ checkpoint برسالة واضحة

    $ git push -u origin <branch-name>

    أول push للـbranch، يربطه بـGitHub

    $ git push

    بعدها: ترفع أي commits جديدة

    $ git pull

    تجيب آخر التحديثات قبل ما تبدأ شغل جديد

    # UNDO

    $ git log --oneline

    تشوف كل الـcheckpoints

    $ git restore <file>

    تلغي تعديلاتك على ملف، قبل الـcommit

    $ git revert <hash>

    تلغي commit بأمان، بدون ما تمسح التاريخ

    $ git merge --abort

    تلغي الـmerge وترجع زي ما كنت لو تلخبطت في conflict

    $ git push --force

    لا تستخدمه: يمسح شغل غيرك
